# Gold Price Forecast

Gold price forecasting tool with Python analysis and Typst document generation.

## Features

- Gold price data analysis
- Forecasting model
- Typst document output (definition.pdf)

## Tech Stack

- Python
- Typst

## Getting Started

```bash
python main.py
```

## Contents

- `main.py` - Analysis and forecasting script
- `definition.typ` - Typst document source
- `definition.pdf` - Generated PDF report
